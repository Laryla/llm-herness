# 分诊标签

工程 Skills 使用五种标准分诊角色。本文件将这些角色映射到仓库 Issue Tracker 中的实际标签。

| Skill 中的标准角色 | 仓库中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估该 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已经完整，可以交给 Agent 独立执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或处理 |
| `wontfix` | `wontfix` | 已确认不处理 |

当 Skill 提到某个角色（例如“应用可交给 Agent 的标签”）时，使用本表中对应的仓库标签。

如果仓库以后更换标签命名，只修改右侧“仓库中的标签”列。
